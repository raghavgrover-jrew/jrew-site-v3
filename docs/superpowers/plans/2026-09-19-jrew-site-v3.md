# jrew-site-v3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (inline, single autonomous session). Steps use checkbox (`- [ ]`) syntax for tracking. Content sources are in `PLAN.md` section 2; design tokens are Direction A in `PLAN.md` section 3.

**Goal:** Build jrew.co.in v3 as a light-first, brochure-faithful Next.js 16 site with server-rendered content, the RFQ path, 14 verification gates green, deployed as a Vercel preview.

**Architecture:** App Router with server components for every page; client islands only for GSAP, Lenis, filters, dialogs and forms. A typed data layer under `src/data/` transcribed from the 2026 brochure, each record tagged with its source spread. Motion enhances complete HTML; `gsap.matchMedia` gates every scroll effect behind `prefers-reduced-motion: no-preference`.

**Tech Stack:** Next 16.3, React 19.2, TypeScript 5.9, Tailwind v4, GSAP 3.15 + @gsap/react, Lenis 1.3, framer-motion 13, nodemailer 10, dotted-map 3, vitest 5, Playwright 1.63 + axe-core, Lighthouse 12.
